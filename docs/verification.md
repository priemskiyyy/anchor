# Verification matrix

A library whose rule is to report only what the provider proves should say the same of itself. This page says what has been exercised, how, and what has not. See [testing](testing.md) to write your own tests over the same mock, and [writing an adapter](writing-an-adapter.md) for the conformance suite every client adapter passes.

## How each layer is tested

| Layer        | How it is tested                                                                                                                                                                                                                                                                                                                             | What that does not cover                                                                                |
| ------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| Core         | Behavior files over the mock adapter (lifecycle, identity, tokens, endings, diagnostics, containment, hints), the eight race invariants and the specification's twenty-five scenarios as named tests, a seeded fast-check sweep of 300 interleavings, and a React Native test with an `AbortSignal` that has only `aborted` and no `crypto`. | Real timers under load, and Hermes itself: the React Native test runs in Node.                          |
| Types        | A consumer-view `tests/types/public-api.ts` against the built package, and a `*.contracts.ts` beside the core, every binding and every adapter; an adapter's contracts file assigns the real SDK to its structural type.                                                                                                                     | TypeScript versions other than the one this repository pins.                                            |
| Adapters     | Conformance through a real Anchor, a fake modelled on a named SDK version, a contracts file against the real SDK's types, and a real-SDK test where the SDK runs in Node or jsdom, against in-process provider endpoints.                                                                                                                    | The providers' own servers, and native SDKs nothing here can run.                                       |
| Bindings     | Real framework testing libraries in jsdom: a hook outside its provider, passivity (nothing started or read), the state followed, selector stability, no listener left after unmount, Strict Mode or a remount starting and disposing nothing, a server render with no `window`, and hydration of the server's markup without a mismatch.     | A real browser, React Native's renderer, and the meta-frameworks: Next.js, Nuxt, SolidStart, SvelteKit. |
| Devtools     | A real shadow root in jsdom, queried by role, over a real Anchor on the mock: live listeners counted, no provider demand from mounting, opening, filtering, pausing or unmounting, no token, cookie or provider error anywhere in the markup with values shown, each wrapper through its own binding, and a server render of each.           | The panel's own tests ran in jsdom only, and hydrating the Solid wrapper's server host was not tested.  |
| Hints        | jsdom against a real Anchor over the mock. `crossTab()` against a fake modelled on the HTML `BroadcastChannel` and once against Node's real one; `appState()` against a fake modelled on React Native's `AppState` since 0.65, and typechecked against React Native 0.86.3's own.                                                            | A device, and a real browser's tab lifecycle.                                                           |
| Server reads | An in-process fake server adapter, including request isolation with reads settled in reverse order, and `testServerSessionAdapter` over every server adapter.                                                                                                                                                                                | A deployed server, a CDN in front of it, and the providers' own servers.                                |
| Mutation     | `scripts/mutate.mjs` breaks sixteen rules on purpose, from the commit rule to an adapter that ends another user's session or a tab that tells another who is signed in, and requires the tests to fail for each.                                                                                                                             | Rules outside the curated sixteen.                                                                      |
| Docs         | `verify:snippets` typechecks every TypeScript fence of these pages and of every package README against the built packages, except the fences marked as fragments; `verify:docs` checks the built site's links, anchors, headings, descriptions, `llms.txt` and a page for every package.                                                     | Whether an example's comment matches what it would print, and code on the Silo and Simulcast pages.     |
| Examples     | Vitest drives the Session Lab through its buttons; `pnpm test:examples` builds the examples and drives them in Chromium through Playwright, the devtools in their shadow root included, outside `pnpm check`.                                                                                                                                | Other browsers, and every real provider SDK, since the lab simulates them.                              |

## What none of this proves

- No adapter has run against its provider's real servers from this repository: no Firebase project or emulator, Supabase project, Auth0 tenant, Clerk instance, Microsoft Entra tenant, Cognito user pool, WorkOS environment, Okta org, Keycloak server or other OpenID Connect provider. The in-process endpoints stand in for them, modelled on the SDKs' own requests.
- Nothing has run on an iOS or Android device, in a simulator, in Hermes or in Expo Go. Every React Native claim rests on a fake typechecked against the real SDK's declarations, and on the SDK's JavaScript run in Node with its native modules replaced.
- Browser flows that need a real browser were not run: redirects, popups, hidden iframes, hosted pages and cross-tab storage events outside jsdom.
- No binding has run inside its meta-framework: Next.js, Nuxt, SolidStart or SvelteKit.
- The HTTP adapter has never sent a request over a real network.
- The [Silo](silo.md) and [Simulcast](simulcast.md) recipes were written from those libraries' sources and neither typechecked nor run here.

## Checking it yourself

```sh
pnpm install --frozen-lockfile
pnpm check
pnpm check:release
pnpm test:examples
```

`pnpm check` builds the packages and runs TypeScript, ESLint, the lint-rule probes, the inferred-`any` scan, Prettier and the unit tests. `pnpm check:release` adds the documentation checks, the package and release metadata checks, the example builds and mutation testing. `pnpm test:examples` builds the examples and runs their browser tests in Chromium through Playwright.
